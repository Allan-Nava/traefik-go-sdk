# Branch Protection

Main branch is protected.

## Rules

- ✓ Require 1 PR review
- ✓ Require status checks (Go build + test)
- ✓ Dismiss stale approvals
- ✓ Require up-to-date branch
- ✓ Prevent force push
- ✓ Prevent deletion

See [.github/BRANCH_PROTECTION.md](../../.github/BRANCH_PROTECTION.md) for setup.
