# Info Endpoints

Health, version, and raw data endpoints.

## Methods

- `HealthCheck()` - Check Traefik health
- `GetApiOverview()` - Get API overview
- `GetApiVersion()` - Get Traefik version (2.x+)
- `GetApiRawData()` - Get raw config data (2.x+)
- `GetEntrypoints()` - List entry points

See [HTTP API](http.md) for usage examples.
